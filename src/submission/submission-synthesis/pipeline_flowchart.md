# MAMA-SYNTH Pipeline 流程图

## 1. 训练阶段

```
┌─────────────────────────────────────────────────────────────────┐
│                        训练数据准备                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  input/pre.mha ──┐                                              │
│                  ├──→ Dataset932 (4ch) ──→ breast_mask.mha      │
│  ground_truth/gt.mha ─┘     (nnUNet)        (可选,训练时用)       │
│                                                                 │
│  mask/tumor.mha ─────────────────────→ tumor_mask (训练时用)      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                        模型训练                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  input (pre) ──→ resize 512 ──→ ┌──────────────┐               │
│                                 │  Pix2PixHD   │               │
│                                 │  Generator   │──→ fake (pred) │
│                                 │  (Residual)  │               │
│                                 └──────────────┘               │
│                                                                 │
│  Loss = GAN + VGG + Feature Match + MSEC + Tumor L1            │
│         ↑                         ↑         ↑                   │
│     fake vs gt              subtraction  mask区域               │
│                            多尺度一致性   加权L1                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
                     weights/latest_net_G.pth


## 2. 推理阶段 (Docker 容器内)

```
┌─────────────────────────────────────────────────────────────────┐
│  GC 平台                                                         │
│                                                                 │
│  /input/images/pre-contrast-dce-mri-slice-breast/<uuid>.mha     │
│                              │                                  │
└──────────────────────────────┼──────────────────────────────────┘
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  你的 Docker 容器 (inference.py)                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  读取 pre.mha (任意分辨率, z-score float32)                       │
│       │                                                         │
│       ▼                                                         │
│  resize → 512×512                                               │
│       │                                                         │
│       ▼                                                         │
│  ┌──────────────────────┐                                       │
│  │   Pix2PixHD Generator │                                      │
│  │   output = pre + Δ    │                                      │
│  └──────────────────────┘                                       │
│       │                                                         │
│       ▼                                                         │
│  resize → 原始分辨率                                              │
│       │                                                         │
│       ▼                                                         │
│  写出 prediction.mha (保留原始 spacing/origin/direction)          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  /output/images/synthetic-contrast-dce-mri-slice-breast/output.mha
└─────────────────────────────────────────────────────────────────┘


## 3. 评估阶段 (GC 平台自动执行)

```
┌─────────────────────────────────────────────────────────────────┐
│  GC 评估系统                                                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  你的 output.mha ──┐                                             │
│                    ├──→ MSE, LPIPS          (Image Fidelity)    │
│  GT post.mha ──────┘                                            │
│                                                                 │
│  你的 output.mha ──┐                                             │
│  GT post.mha ──────┼──→ SSIM_tumor, FRD    (ROI Realism)       │
│  tumor_mask ───────┘                                            │
│                                                                 │
│  你的 output.mha ──→ 分类器 ──→ AUROC       (Classification)    │
│                                                                 │
│  你的 output.mha ──→ nnUNet ──→ Dice, HD95  (Segmentation)     │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│  最终排名 = 4组指标各组排名的平均                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 关键点

- **训练时**: 有 pre + GT + mask，可以用 4ch 分割模型生成 breast mask
- **推理时**: 只有 pre，什么辅助模型都不用，纯 Generator 一次前向
- **评估时**: GC 平台自动做，你不需要做任何事
